# 브롤 퀴즈 🎮

슈퍼셀 **브롤스타즈**를 주제로 한 팬메이드 비영리 퀴즈 게임입니다.
실제 게임 이미지(브롤러 모델·초상화, 가젯·스타 파워 아이콘, 맵)를 사용합니다.

## 퀴즈 모드

| 모드 | 설명 |
| --- | --- |
| 랜덤 믹스 | 모든 유형이 섞여서 출제 |
| **브롤러** | |
| 브롤러 맞히기 | 브롤러 모습을 보고 이름 맞히기 |
| 실루엣 퀴즈 | 검은 그림자만 보고 맞히기 |
| 줌 퀴즈 | 크게 확대된 초상화 일부만 보고 맞히기 |
| 핀 퀴즈 | 기본 핀(이모지) 표정을 보고 맞히기 |
| 설명 퀴즈 | 게임 속 브롤러 소개글(이름은 가려짐)을 보고 맞히기 |
| **능력·아이템** | |
| 가젯 퀴즈 | 가젯 아이콘·이름을 보고 주인 찾기 |
| 스타 파워 퀴즈 | 스타 파워 아이콘·이름을 보고 주인 찾기 |
| 하이퍼차지 퀴즈 | 하이퍼차지 이름을 보고 주인 찾기 |
| 스킬 퀴즈 | 기본 공격·궁극기 이름을 보고 주인 찾기 |
| 기어 퀴즈 | 기어 아이콘을 보고 이름 맞히기 |
| 스킨 퀴즈 | 스킨 이름(브롤러 이름은 가려짐)을 보고 주인 찾기 |
| **정보·능력치** | |
| 희귀도 퀴즈 | 브롤러의 희귀도 맞히기 |
| 역할군 퀴즈 | 탱커/저격수/어쌔신 등 역할군 맞히기 |
| 체력 비교 | 두 브롤러 중 체력이 더 높은 쪽 고르기 |
| 속도 비교 | 두 브롤러 중 이동 속도가 더 빠른 쪽 고르기 |
| **맵** | |
| 맵 모드 퀴즈 | 맵 이미지를 보고 게임 모드 맞히기 |
| 맵 이름 퀴즈 | 맵 이미지를 보고 맵 이름 맞히기 |

- 한 판에 10문제, 문제당 15초 제한
- 점수 = 정답 100점 + 남은 시간 보너스 + 연속 정답 보너스
- 모드별 최고 점수는 브라우저에 저장됩니다
- 키보드 `1`~`4`로 보기 선택, `Enter`로 다음 문제

## 실행 방법

빌드가 필요 없는 정적 웹페이지입니다. `index.html`을 브라우저로 열거나 로컬 서버로 실행하세요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

배포 주소: https://brawlsquiz.vercel.app
(Vercel 프로젝트가 저장소에 연결되어 있어 푸시할 때마다 자동으로 배포됩니다)

## 데이터 갱신

브롤러·맵 데이터는 [BrawlAPI](https://brawlapi.com)에서 받아 `js/data.js`에 저장되어 있고,
이미지는 Brawlify CDN에서 불러옵니다. 새 브롤러가 나오면 아래 명령으로 갱신하세요
(이미지가 없는 항목은 자동으로 제외됩니다).

```bash
python3 scripts/update_data.py
```

브롤러·가젯·스타 파워·하이퍼차지·스킬·기어·스킨·맵·모드 이름과 브롤러 소개글,
희귀도·역할군·능력치는 모두
게임 원본 한국어 번역 파일(BrawlAPI `localization/kr`)에서 가져오므로 게임 속 공식 표기와 같습니다.

## 구성

```
index.html              화면 마크업
css/style.css           스타일
js/app.js               퀴즈 로직
js/data.js              브롤러·맵 데이터 (자동 생성)
scripts/update_data.py  데이터 갱신 스크립트
```
